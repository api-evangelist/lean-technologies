Lean Technologies is a MENA open finance and payments infrastructure platform serving the United Arab Emirates and Saudi Arabia. Its APIs let businesses connect to customers' bank accounts to read financial data (accounts, balances, transactions, identity, income and credit insights) and to move money via pay-by-bank payments, Account-on-File consents, payment links, payouts, refunds and scheduled payments. Lean provides the LinkSDK client for web, iOS, Android, React Native and Flutter, a FAPI-grade OAuth 2.0 authorization server, webhooks, a hosted documentation MCP server, and public Postman collections. Lean is regulated under the UAE Open Finance (CBUAE) and Saudi Open Banking (SAMA) frameworks and is SOC 2 Type II and ISO 27001 certified.

**Areas:** Open Banking · Open Finance · Payments · Financial Data · Fintech · MENA · United Arab Emirates · Saudi Arabia · Pay by Bank · Bank Data · Account Verification · Payouts

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Lean Technologies: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
